# Laundry Wallah / Laundry Mart

## Project Description
Laundry Wallah / Laundry Mart is a simple HTML webpage designed for a laundry service business. It provides information about laundry services, pricing, and booking details.

## Features
- Welcome and About section
- Laundry service list
- Price list in table format
- Booking form with Name, Email, and Phone fields
- Contact information in the footer
- Washing machine image

## Technologies Used
- HTML5

## Project Structure
- `index.html` – Main webpage
- `README.md` – Project documentation

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index1.html` in any web browser.
4. The Laundry Wallah webpage will appear.

## Purpose
The purpose of this project is to create a simple, user-friendly laundry service webpage using HTML.
